# Technet Viewer sources

Normal delivery: repository-root `technetViewer.html`, generated by:

```
node tools/build-technet-viewer.mjs --write
node tools/build-technet-viewer.mjs
node tools/pack-technet-viewer.mjs --date 2026-11-09 --out dist/<new-name>.zip
```

Edit `index.html.in`, `src/viewer.css`, `src/viewer.js` and the existing shim here.
`vendor/` preserves the embedded MapLibre version and license from the existing delivery.
`src/import-legacy.js.in` preserves the existing bundled import implementation;
it is not a newly modularized domain parser. Its GRA and DBB placeholders are
filled exclusively from shared `src/import/parsers/technet/` sources by
`tools/technet-shared-blocks.mjs`. The remaining legacy parser is deliberately
preserved until a separately tested package migrates it.

The builder checks every generated byte and `source-manifest.json`. Do not edit
the generated root HTML independently. The packer refuses stale output and
existing destination ZIPs; it adds build metadata and QUELLEN.json. No temporary
Claude scratchpad file is required. `arbeitsgrundlage.html` was an independent
working document, not the source of this product.
