\begin{remark}
This part addresses the relation between the mathematical model and the
real world.
Railway alignments are not only theoretical objects, but are embedded in
coordinate systems, measurement processes, construction workflows, and
imperfect data.
\end{remark}

\begin{remark}
A realistic alignment framework must therefore account for:
\begin{itemize}
\item coordinate reference systems,
\item measurement uncertainty,
\item special railway elements,
\item and the distinction between designed and realized geometry.
\end{itemize}
\end{remark}

\begin{remark}
The following chapters develop this reality layer as an essential part
of alignment-based information modelling.
\end{remark}
