\chapter{Kilometre Line and Stationing}

\label{chap:km-line-and-stationing}

\index{Reference system!stationing}

Stationing is the operational addressing layer of railway systems. It is
not identical to constructive alignment identity, metric embedding, or
realized geometry.

% ============================================================
\section{Stationing Role}
% ============================================================

\begin{definition}[Kilometre line]
\index{Reference system!kilometre line}
A kilometre line is a longitudinal reference structure that assigns
station values within a route context.
\end{definition}

\begin{definition}[Stationing layer]
\index{Reference system!stationing layer}
The stationing layer maps railway positions to operational address
values.
\end{definition}

Stationing answers how an infrastructure position is addressed;
geometry answers what shape is realized; CRS answers where embedding is
expressed.

% ============================================================
\section{Relation to Geometry}
% ============================================================

A kilometre line may coincide with a physical track centerline, but this
is not required. In multi-track and junction contexts, several physical
alignments can reference one stationing structure.

\begin{definition}[Outer stationing]
\index{Reference system!outer stationing}
Outer stationing describes mapping between a physical track alignment
coordinate and an external kilometre reference.
\end{definition}

Outer stationing is required when station reference and physical track
reference do not coincide.

% ============================================================
\section{Layer Separation}
% ============================================================

\begin{proposition}
Railway modelling requires separation of
\[
\text{spatial embedding}
\neq
\text{geometric alignment}
\neq
\text{stationing reference}.
\]
\end{proposition}

Confusing these layers yields systematic errors in interpretation,
network addressing, and target--realized comparison.

% ============================================================
\section{Topology and Operational Continuity}

\index{Topology!operational continuity}
% ============================================================

Kilometre references provide operational continuity across track changes,
branches, station areas, and route transitions, even where geometric
continuity is represented by multiple physical alignments.

% ============================================================
\section{Connection to AIM}
% ============================================================

\begin{summary}
In AIM, stationing is an explicit reference layer used for operational
addressing and comparison workflows.

It remains distinct from constructive identity, CRS embedding, and
realized track geometry.
\end{summary}
