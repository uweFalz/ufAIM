\chapter{Problem Statement}

\section{From Motivation to Formalization}

The previous chapter has argued that railway alignment design is
intrinsically a coupled problem involving geometry, dynamics,
and engineering constraints.

We now formulate this insight as a precise problem statement.

\section{Core Deficiency of Existing Approaches}

Current alignment models are predominantly:
\begin{itemize}
\item element-based,
\item geometry-centered,
\item and weakly connected to dynamic behaviour.
\end{itemize}

As a consequence, they exhibit the following structural deficiencies:
\begin{itemize}
\item curvature is not treated as a primary design variable,
\item cant is handled in a separate design process,
\item dynamic quantities are evaluated only after geometric design,
\item optimization is indirect and iterative rather than intrinsic.
\end{itemize}

\section{Formal Gap}

Let
\[
\gamma : [0,L] \to \R^2
\]
denote a planar alignment.

In classical formulations, the curve \(\gamma\) is the primary object,
while curvature is derived as
\[
\kappa(s) = \theta'(s).
\]

However, from a dynamic perspective, the situation is reversed:
\begin{itemize}
\item curvature determines acceleration,
\item curvature variation determines jerk,
\item and therefore curvature governs physical behaviour.
\end{itemize}

This reveals a fundamental mismatch between:
\begin{itemize}
\item geometric modelling (curve-first),
\item and physical interpretation (curvature-first).
\end{itemize}

\section{Missing Coupling of State Variables}

Let
\[
\kappa(s), \quad \phi(s)
\]
denote curvature and cant.

In practice, these variables are strongly coupled through
\[
a_{\mathrm{eff}}(s) = v^2 \kappa(s) - g \sin\phi(s).
\]

Despite this coupling:
\begin{itemize}
\item \(\kappa\) is typically designed geometrically,
\item \(\phi\) is designed in a separate process,
\item and their interaction is only checked afterwards.
\end{itemize}

This separation prevents a unified optimization of the system.

\section{Data and Reality Gap}

Modern railway projects rely heavily on real-world data, including:
\begin{itemize}
\item measurement polylines,
\item legacy alignment descriptions,
\item and heterogeneous coordinate systems.
\end{itemize}

Existing models struggle to:
\begin{itemize}
\item integrate noisy and incomplete data,
\item reconcile different coordinate reference systems,
\item and maintain a consistent representation across scales.
\end{itemize}

This leads to a disconnect between:
\begin{itemize}
\item theoretical alignment models,
\item and real-world engineering data.
\end{itemize}

\section{Lack of a Unified Optimization Framework}

Alignment design problems naturally take the form:
\[
\min J(\kappa,\phi)
\]
subject to geometric and engineering constraints.

However, in current practice:
\begin{itemize}
\item the objective function is implicit or fragmented,
\item constraints are applied in separate stages,
\item and optimization is not formulated as a single problem.
\end{itemize}

This prevents the use of systematic numerical optimization methods.

\section{Target Formulation}

We aim to formulate alignment design as a unified problem:
\[
\text{find } (\kappa,\phi)
\]
such that:
\begin{itemize}
\item geometric consistency is satisfied,
\item engineering constraints are fulfilled,
\item and a global objective functional is minimized.
\end{itemize}

This requires:
\begin{itemize}
\item a curvature-based representation,
\item a coupled state model,
\item and a consistent treatment of data and constraints.
\end{itemize}

\section{Scope of the Problem}

The problem addressed in this work includes:
\begin{itemize}
\item modelling of alignments via curvature functions,
\item integration of cant as a state variable,
\item reconstruction of geometry from curvature,
\item incorporation of engineering rules as constraints,
\item and formulation of optimization problems.
\end{itemize}

The problem explicitly excludes:
\begin{itemize}
\item detailed multibody vehicle dynamics,
\item full infrastructure modelling,
\item and construction-specific considerations.
\end{itemize}

\section{Research Questions}

The following central questions arise:
\begin{itemize}
\item How can alignment be represented in a curvature-driven manner?
\item How can curvature and cant be modelled as a coupled state?
\item How can real-world data be integrated into such a model?
\item How can engineering rules be expressed as mathematical constraints?
\item How can alignment design be formulated as an optimization problem?
\end{itemize}

\section{Working Hypothesis}

We hypothesize that:
\begin{itemize}
\item a curvature-based state representation,
\item combined with a unified optimization framework,
\end{itemize}
provides a more consistent and powerful foundation for railway alignment design.

In particular, we assume that:
\begin{itemize}
\item transition curves emerge naturally from optimization,
\item geometry and dynamics can be unified,
\item and real-world data can be systematically integrated.
\end{itemize}

\section{Summary}

\begin{summary}
Current alignment design methods suffer from fragmentation between
geometry, dynamics, and data.

This work addresses the problem of developing a unified,
curvature-driven framework that integrates these aspects into a
single coherent model.

The goal is to enable consistent modelling, analysis, and optimization
of railway alignments.
\end{summary}
