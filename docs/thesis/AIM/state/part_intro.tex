The straight--transition--arc Alignment from the preceding part is still the
engineering object under discussion. Its identity, ordered construction,
intrinsic parameter \(s\), curvature law \(\kappa(s)\), Berlinish transition
partition, provenance, and applicability have already been established.
State therefore does not begin with an anonymous coordinate tuple. It begins
with a question about this identified object:

\begin{quote}
At a selected \(s\), what railway state follows from the Alignment, and which
additional laws and realization data are required to obtain it?
\end{quote}

Curvature first determines change of heading and, with a starting pose, a
planar trajectory. Vertical geometry and cant then add independent
longitudinal laws. A stated frame convention combines these inputs into a
spatial railway interpretation. Only after speed and, where necessary, a
vehicle model are supplied do acceleration and other operational quantities
follow. Evaluation for a purpose is later still: a computed consequence is
not an engineering decision.

evaluation result does not decide whether a proposal is accepted.

\section*{A Narrow Explanatory Contract}

For this part, a \emph{railway-state record} may be read as the following
Thesis-level explanatory structure:
\[
\mathcal S_{\mathrm{rail}}(s)=
\bigl(
\mathrm{AlignmentRef},s,\mathrm{pose},F,\kappa,
\mathrm{vertical},\mathrm{cant},\mathrm{realization},
\mathrm{provenance},t_{\mathrm{valid}},\mathrm{derived}
\bigr).
\]
Speed is included only for a speed-qualified use. Observation provenance is
included only for an observed-state estimate. This tuple is not a new
canonical Kernel concept and not a universal storage schema; it merely keeps
the dependencies and qualifications visible while the argument proceeds.

The chapters now follow one dependency chain:
\begin{align*}
\text{Alignment identity}&\rightarrow s\rightarrow\kappa(s)
\rightarrow\mathrm{pose2}\rightarrow\text{moving frame}\\
&\rightarrow\text{elevation and cant}
\rightarrow\mathrm{pose3}\\
&\rightarrow\text{speed-derived quantities}
\rightarrow\text{purpose-qualified evaluation}.
\end{align*}

\begin{principle}[Railway-State Principle]
\label{princ:railway-state}
Railway state is derived from an identified Alignment under stated additional
laws, realization data, conventions, and use qualifications. No resulting
pose, coordinate representation, observation, or evaluation owns the
Alignment's identity or authority.
\end{principle}

\begin{summary}
Part V is the physical unfolding of the already identified Alignment. It
introduces each state quantity only when an engineering consequence requires
it.
\end{summary}
