\chapter{Introduction}

\section{Background}

\begin{remark}
Railway alignment design is a fundamental task in infrastructure
engineering.
\end{remark}

\begin{remark}
It defines not only the geometric path of a railway track, but also
strongly influences construction cost, operational efficiency,
passenger comfort, and long-term maintenance.
\end{remark}

\begin{remark}
Over time, a rich body of methods has evolved, combining geometric
principles, engineering rules, and practical experience.
\end{remark}

---

\section{Current State of Practice}

\begin{remark}
Despite this long tradition, alignment modelling is still largely
fragmented across several domains:
\begin{itemize}
\item geometric construction of curves,
\item rule-based engineering design,
\item data exchange via formats such as LandXML and IFC,
\item numerical evaluation and simulation.
\end{itemize}
\end{remark}

\begin{remark}
These aspects are typically handled in separate tools and workflows,
leading to discontinuities between modelling, analysis, and design.
\end{remark}

\begin{remark}
In particular:
\begin{itemize}
\item geometry is often treated independently of dynamics,
\item transition curves are selected from predefined catalogues,
\item data formats focus on representation rather than computation,
\item optimization is rarely integrated as a core modelling principle.
\end{itemize}
\end{remark}

---

\section{Problem Statement}

\begin{remark}
The lack of a unified modelling framework leads to several fundamental
limitations:
\end{remark}

\begin{itemize}
\item inconsistent interpretation of alignment data,
\item separation of geometry and dynamics,
\item limited support for optimization-based design,
\item high effort for integrating heterogeneous data sources.
\end{itemize}

\begin{remark}
These issues become increasingly critical as infrastructure projects
grow in complexity and demand higher levels of precision and
automation.
\end{remark}

---

\section{Motivation}

\begin{remark}
The motivation of this work is to develop a framework that unifies
alignment modelling across geometry, dynamics, and computation.
\end{remark}

\begin{remark}
Such a framework should:
\begin{itemize}
\item provide a consistent internal representation,
\item support dynamic interpretation,
\item enable numerical reconstruction,
\item integrate optimization as a natural component,
\item bridge the gap between data standards and engineering reasoning.
\end{itemize}
\end{remark}

---

\section{AIM: Alignment-Based Information Modelling}

\begin{remark}
This work introduces Alignment-Based Information Modelling (AIM) as a
framework addressing the above challenges.
\end{remark}

\begin{remark}
The central idea is to represent railway alignment as a structured,
state-based object defined by:
\[
(\gamma(s), \theta(s), \kappa(s), \phi(s)).
\]
\end{remark}

\begin{remark}
Within this framework:
\begin{itemize}
\item alignment is treated as a dynamic system,
\item curvature becomes the primary modelling variable,
\item transition curves are interpreted as control functions,
\item geometry and dynamics are unified.
\end{itemize}
\end{remark}

---

\section{Scope of the Work}

\begin{remark}
The present manuscript develops the AIM framework across several
dimensions:
\end{remark}

\begin{itemize}
\item mathematical foundations of alignment modelling,
\item structured representation of alignment elements,
\item classification of transition curves,
\item numerical reconstruction methods,
\item dynamic interpretation and modelling,
\item formulation of optimization problems,
\item integration with real-world data formats,
\item application to railway engineering use cases.
\end{itemize}

---

\section{Contribution}

\begin{remark}
The main contributions of this work are:
\end{remark}

\begin{itemize}
\item the introduction of a unified state-based alignment model,
\item the reinterpretation of transition curves as curvature control functions,
\item the formulation of alignment design as an optimization problem,
\item the development of a normalization pipeline for heterogeneous data,
\item the proposal of BIMalignment as an extension of BIM principles.
\end{itemize}

\begin{remark}
Together, these contributions establish a coherent framework that
connects theory, computation, and engineering practice.
\end{remark}

\section{Structure of the Manuscript}

\begin{remark}
The manuscript is organized into the following parts:
\end{remark}

\begin{itemize}
\item \textbf{Foundations:} mathematical and conceptual basis,
\item \textbf{Model:} structured representation of alignment,
\item \textbf{Analysis:} numerical, dynamic, and optimization aspects,
\item \textbf{Reality:} data formats and standards,
\item \textbf{Applications:} engineering use cases and perspectives.
\end{itemize}

\begin{remark}
Each part builds upon the previous ones, forming a progression from
theoretical concepts to practical implementation.
\end{remark}

\section{Outlook}

\begin{remark}
The AIM framework is intended as a foundation rather than a final
solution.
\end{remark}

\begin{remark}
It opens the way toward:
\begin{itemize}
\item dynamic and optimization-driven design systems,
\item deeper integration with BIM,
\item network-level modelling,
\item interactive and real-time engineering tools.
\end{itemize}
\end{remark}

\begin{remark}
In this sense, the work contributes to a broader transition from static
geometry toward computational infrastructure modelling.
\end{remark}
