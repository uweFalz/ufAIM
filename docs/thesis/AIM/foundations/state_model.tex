\chapter{State Transition}
\label{chap:state-model}

Suppose an engineer edits curvature on an interval
\(J\subseteq I\), replacing \(\kappa(s)\) by
\(\widetilde\kappa(s)=\kappa(s)+\Delta\kappa(s)\). Curvature changes
directly. Downstream heading and position change through integration;
cant changes only if its own control is edited or a coupling constraint
requires it. The alignment identity, the initial condition chosen for
reconstruction, and the applicable realization context remain fixed
unless the engineering task explicitly changes them.

This single edit establishes the purpose of a state model: to answer
which condition follows from declared inputs under a stated context. It
does not describe a storage snapshot and is not a generic container for
every property associated with the alignment.

\section{The state that answers the question}

\begin{definition}[Engineering state]
\label{def:state}
An engineering state is a structured description of an engineering
object under a specified condition and within a specified context.
\end{definition}

For the present question, a state trajectory is
\[
x:I\rightarrow\mathcal X,
\qquad s\longmapsto x(s).
\]
The mapping records the quantities needed to propagate the edit. A file
record, cached polyline, or database row may represent values of this
trajectory, but storage does not determine which condition or context
those values describe.

\section{Planar transition driven by curvature}

\begin{definition}[pose2]
\label{def:notation-pose2}
The planar alignment state is
\begin{equation}
\mathrm{pose2}(s)=\bigl(\gamma(s),\theta(s)\bigr),
\label{eq:pose2-definition}
\end{equation}
where \(\gamma(s)\) is planar position and \(\theta(s)\) heading.
\end{definition}

Its evolution is
\begin{equation}
\begin{aligned}
\gamma'(s)&=
\begin{pmatrix}\cos\theta(s)\\\sin\theta(s)\end{pmatrix},\\
\theta'(s)&=\kappa(s).
\end{aligned}
\label{eq:pose2-evolution}
\end{equation}

With \(\gamma(s_0)\) and \(\theta(s_0)\) fixed, applying
\(\widetilde\kappa\) produces a new state trajectory
\(\widetilde{\mathrm{pose2}}\). Inside and downstream of the edited
interval, heading must be reintegrated and position reconstructed. An
existing CAD curve or sampled polyline derived from the former trajectory
is consequently stale until its representation is regenerated.

\paragraph{Execution contract.}
The transition receives the curvature edit, reconstruction interval, and
initial pose; it produces a planar state trajectory. It assumes
arc-length parameterization and the stated boundary conditions. It
preserves alignment identity. Its result inherits the provenance of the
edit and boundary conditions. It cannot infer whether the edit is
permitted, whether a survey concerns the same condition, or whether the
result should be accepted.

\section{Spatial transition and controls}

\begin{definition}[Foundational pose3 state]
\label{def:pose3}
The foundational spatial railway state is
\begin{equation}
\mathrm{pose3}(s)=\bigl(\gamma(s),\theta(s),\phi(s)\bigr),
\label{eq:pose3-definition}
\end{equation}
where \(\phi(s)\) is cant rotation about the local tangent.
\end{definition}

This is the intrinsic input to a later spatial construction, not a
world-space pose. Profile, metric context, and frame construction are
still required before it becomes spatially measurable.

\begin{definition}[Foundational controls]
\label{def:control-quantities}
The foundational control pair is
\begin{equation}
u(s)=\bigl(\kappa(s),\omega(s)\bigr),
\qquad \omega(s)=\phi'(s).
\label{eq:pose3-controls}
\end{equation}
\end{definition}

The controls propagate the state through
\begin{equation}
\begin{aligned}
\gamma'(s)&=
\begin{pmatrix}\cos\theta(s)\\\sin\theta(s)\end{pmatrix},\\
\theta'(s)&=\kappa(s),\\
\phi'(s)&=\omega(s).
\end{aligned}
\label{eq:pose3-evolution}
\end{equation}

\section{Degrees of freedom during the edit}

The edit is interpretable only when the status of each quantity is
explicit.

\begin{description}
\item[Fixed:] alignment identity, applicable context, reconstruction
  origin, and any boundary values declared invariant by the task.
\item[Edited:] \(\kappa\) on \(J\), with source, author, and scope as
  provenance.
\item[Derived:] heading, tangent, planar position, and every
  representation sampled from the changed trajectory.
\item[Coupled:] cant, profile, or adjoining transition quantities when an
  applicable engineering relation links them to the curvature edit.
\item[Constrained:] continuity, regularity, boundary, admissibility, and
  project-specific requirements supplied by the applicable knowledge.
\item[Free:] quantities not fixed, derived, coupled, or constrained by
  the declared problem. They remain candidate degrees of freedom; a
  solver may explore them but cannot assign them engineering authority.
\end{description}

This classification is the bridge from formal state propagation to
alignment-transition design: it identifies the variables available to a
later construction or optimization method without prescribing software
or a particular solver.

\section{What may be compared}

Metric realization can make the revised state spatially measurable. A
survey polyline may then provide observational evidence in a compatible
context, and an evaluation operator may compute residuals. The
comparison relates qualified states and sources; it does not turn the
polyline into physical reality, replace the alignment's constructive
definition, or convert an evaluation into a decision.

The next chapter makes the actions in this chain explicit as typed
operators.
