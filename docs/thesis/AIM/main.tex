\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This manuscript is intended as a long-term scientific foundation for
alignment-based information modelling.

It is not merely software documentation, but a structured knowledge base
covering:
\begin{itemize}
\item intrinsic railway geometry,
\item curvature-driven reconstruction,
\item runtime evaluation,
\item realization processes,
\item vehicle-space interpretation,
\item optimization,
\item and Earth-attached railway geometry.
\end{itemize}

The AIM framework treats railway alignments not merely as static curves,
but as coupled operator-based state systems connecting geometry,
construction, runtime interpretation, and operational behaviour.
