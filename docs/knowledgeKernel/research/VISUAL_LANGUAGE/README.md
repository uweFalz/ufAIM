# Three Faces of the Knowledge Kernel

Status: Research; non-canonical; not final Thesis artwork.

This package compares exactly three visual identities for the ufAIM Knowledge Kernel. Each is an evidence-based model, not a decorative logo proposal. The visible vocabulary is limited to responsibilities actually present in the active Kernel: intrinsic Alignment Identity and curvature evolution; explicit Metric Realization; representation and observation as distinct from reality and identity; evaluation; and accountable authority.

## Recommendation

1. **Primary — Intrinsic Spine.** Use for a later Thesis title-page implementation. It is the most railway-specific, legible at thumbnail size, and faithful to the Kernel’s strongest distinctive statement: an Alignment owns intrinsic longitudinal order and curvature evolution, while realized coordinates remain downstream.
2. **Reserve — Kernel Loom.** Use when the institutional architecture must be foregrounded. It accurately shows Research entering the Kernel and Thesis/Reference Implementation deriving from it without implying that either defines the Kernel.
3. **Rejected for cover, useful elsewhere — Evidence Aperture.** Use for chapter openers and diagrams about realization, observation, evaluation, and authority. It is truthful and powerful, but reads as a process before it reads as “Knowledge Kernel.”

The recommendation is a Research result, not approval of a visual identity.

## Evidence basis and semantic guardrails

- `docs/knowledgeKernel/README.md`: Research → Knowledge Kernel → Thesis / Reference Implementation.
- `docs/knowledgeKernel/KERNEL_CONSTITUTION.md`: Research discovers, Governance decides, Kernel preserves, RefImpl demonstrates, Thesis explains.
- `docs/knowledgeKernel/IDENTITY/KC-ID-004_Alignment_Identity.md`: intrinsic longitudinal parameterization, ordered construction, and curvature evolution; coordinates do not own identity.
- `docs/knowledgeKernel/REALIZATION/KC-REALIZATION-001_Metric_Realization.md`: explicit context turns intrinsic definition into measurable state without replacing identity.
- `docs/knowledgeKernel/REALIZATION/KC-REALIZATION-005_Physical_Realization.md`: intended state, physical outcome, observation, and representation remain distinct.
- `docs/knowledgeKernel/EVALUATION/KC-EVAL-001_Engineering_Knowledge.md`: evidence becomes usable knowledge only with scope, provenance, applicability, and authority.
- `docs/knowledgeKernel/EVALUATION/KC-EVAL-002_Engineering_Observation.md`: observation is source-grounded evidence, not observed reality.
- `docs/knowledgeKernel/EVALUATION/KC-EVAL-011_Engineering_Decision.md`: evaluation does not exercise decision authority; the full concept remains evidence-missing.
- `docs/thesis/AIM/main.tex` and `figures/FIGURE_REGISTRY.md`: A4 portrait, Latin Modern, restrained TikZ line language, recurring curvature/state/realization narrative.

The prototypes therefore avoid an invented all-enclosing hierarchy, database/server imagery, generic trains, network graphs, equations presented as proof, and any visual claim that implementation or Thesis controls Kernel meaning.

## Production rules shared by all directions

- Portrait A4 master; one dominant silhouette survives at 120 px height.
- Open SVG only; no external images, fonts, or proprietary assets.
- System serif/sans stacks are placeholders. A final Thesis implementation may use the existing Latin Modern family.
- Color is never the sole carrier of meaning. Shape, line weight, position, and labels survive grayscale conversion.
- English/German compatibility is achieved through short replaceable labels and generous label widths.
- These are composition prototypes. A later title-page mission must integrate bibliographic title matter, edition language, bleed/margins, and print proofing.
