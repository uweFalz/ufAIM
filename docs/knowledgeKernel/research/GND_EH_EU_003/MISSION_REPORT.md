## 4. Work Performed

Question: which GND EH/EU records can become constructive laws without
inventing mathematics, domain, or rail reference?

Tests performed:

- reconciled the bundled VERM.ESN record definition with the consolidated
  checksum-identified GND corpus Research;
- tested uniqueness of each type's law from its available name and parameters;
- applied vertical-family, explicit-zero, scalar-versus-paired-cant, and
  GAP2-D003 counterexamples;
- dimensionally checked the EH 0/1 and EU 0 laws and evaluated the EH 1 witness;
- corrected the EH cross-segment C0 test so that only
  `z0,a + DeltaZa(La)` is compared with `z0,b`, and only for qualified anchors
  in the same `EHSYS`; without those anchors C0 is `not-checkable` while C1
  gradient remains independently testable;
- tested whether domain and reference gaps can be represented explicitly
  without a universal inference.

Findings:

- EH 0 and EH 1 are conditionally `constructive-safe` as source-local laws.
- EU 0 is conditionally `constructive-safe` only as a scalar source-cant law.
- EU 2/3/4 are `decision-required`: type names do not select a sufficiently
  evidenced GND interpolation formula.
- EH 2 and EU 7/8 are `evidence-only` special switch/scissor forms.
- explicit domain relations remove the need to guess track distance versus
  kilometre-line domain;
- a scalar EU value cannot become authoritative paired rails without the exact
  GND source convention and reversible midpoint transformation.

Confidence is high for field identity, units, EH 0/1 mathematics, explicit
zero, and GAP2-D003 boundaries; medium for the conditional EU 0 scalar
interpretation; deliberately insufficient for special/ramp interior formulae.
