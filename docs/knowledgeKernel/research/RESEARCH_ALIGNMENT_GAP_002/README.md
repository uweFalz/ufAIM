# RESEARCH-ALIGNMENT-GAP-002

## Vertical, Cant, Domain, State, and Persistence Contracts

This non-canonical Research package refines five open parts of the Positive
Railway Alignment Nucleus:

1. vertical geometry;
2. cant/superelevation;
3. the common intrinsic domain;
4. explicit zero versus unknown;
5. behaviorally equivalent persistence.

## Outcome

`survives with reformulation`

The central result is a two-level contract:

- one **common coordination parameter** `σ`, recommended as directed distance
  along the horizontal Alignment;
- typed constructive segment laws that preserve their actual mathematical
  family instead of converting everything to a nominally equivalent sampled
  curve.

Vertical parabolas defined by constant `dg/dσ` and vertical circular arcs
defined by constant `dθ/dℓ` are not interchangeable. Cant difference `D` and
paired rail offsets `(cL,cR)` are not interchangeable unless a rail/axis datum
rule is also supplied.

For state, “explicit zero” is not a fourth null marker. It is
`Known(value = 0)` over a declared domain with convention and provenance.
Unknown is a positive epistemic state, not a numeric value.

For persistence, value equality at reopen is insufficient. A lossless working
state must preserve constructive family, conventions, provenance, revision
semantics, query behavior, and the accepted/rejected consequences of a declared
edit-operation set.
