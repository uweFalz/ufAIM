# RESEARCH-ALIGNMENT-GAP-001

## The Positive Railway Alignment Nucleus

This non-canonical Research package asks:

> What is the smallest complete professional unit that can function today as a
> railway Alignment—not merely identify, draw, exchange, or evaluate one?

The answer is the **Positive Railway Alignment Nucleus (PRAN)**: a versioned
engineering aggregate with one intrinsic longitudinal domain and orientation,
three coordinated constructive laws (horizontal, vertical, cant), explicit
operational addressing, network participation, qualified world realization,
purpose-relative speed/dynamic evaluation, reviewable constructive change, and
lossless persistence.

“Minimal” means that no responsibility can be removed without losing a present
engineering action. It does not mean that every optional value must be known.
Absence, zero, local-only placement, disconnection, and unresolved evidence must
be represented explicitly rather than silently invented.

## Outcome

`survives with reformulation`

The requested eight-part nucleus survives, but not as eight co-equal identity
attributes. The evidence supports a **single working aggregate with separated
roles**:

1. constructive spine;
2. reference and context envelope;
3. evaluation envelope;
4. change and continuity contract.

This is a Research candidate, not Kernel approval and not an implementation
schema.

## Reading rule

The package distinguishes:

- **U — universal/domain-established:** repeatedly supported by historical
  engineering, contemporary railway rules, or independent standards;
- **S — ufAIM synthesis:** a proposed integration or role separation assembled
  from established parts;
- **G — open gap:** insufficiently specified, verified, or implemented.

No `S` or `G` item is a canonical Kernel statement.
