## Canonical Boundaries

- Approved freeze [`FC-001`](../FREEZES/FC-001.md): Representation is never Identity.
- Approved freeze [`FC-002`](../FREEZES/FC-002.md): Metric Realization is not Identity.

Therefore:

- Representation is distinct from Identity (see [`../IDENTITY/README.md`](../IDENTITY/README.md)).
- Representation is distinct from Realization (see [`../REALIZATION/README.md`](../REALIZATION/README.md)).
- Representation may describe or communicate, but does not define intrinsic engineering identity.
