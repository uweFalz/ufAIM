- Addendum 4, 2026-11-12, ordered by Uwe ("Tauglichkeitsprüfung auf f″ und f‴ verschärfen"): `cantCurvatureCoupling.js` returns f′, f″, f‴ at both ramp ends (`endDerivatives`) and their largest values (`peaks`); `assessCouplingSuitability` counts the reached order (1: f′ = 0, 2: also f″ = 0, 3: also f‴ = 0) and compares it with `requiredOrder`. Default 2, the patent's minimum of three finite derivatives; 3 is the bending-theory demand. Limits: f′ against 0.02 as before, f″ and f‴ against 0.02 times their largest value on the ramp (at least 1). Called with end slopes only, the function behaves as before. Mode 2 has the select "Verlangte Glattheit der Rampe an den Enden", a graded verdict and the end values in the legend. Consequence: a ramp that is only tangential (Bloss read as cant) no longer counts as suitable by default. The note's section 8 carries the rule and a table.
- Addendum 5, 2026-11-13, on Uwe's answers to section 9 of the note ("1. bestätigt 2. der genaue Ausdruck! 3. 1,8m - aber editierbar 4. f'' = 0 reicht aus"): `cantCurvatureCoupling.js` computes the exact expression κ_ref = (κ + d″)/(1 − κd) with d = h·sin ψ in both directions; new `couplingGeometry(assumption)` gives ε, the end angle ψ_E = arcsin(cant / rail base) and h/R; the options `endAngle` and `offsetRatio` default to 0, which is the small-angle form bit for bit. With curvature given the equation is nonlinear and is solved by iteration on the existing linear solver (`converged`, `iterations`). The service uses the exact form whenever it works from an assumption; a bare ε keeps the small-angle form. Page: the model reservation is replaced by a model line naming the confirmation, the legend shows ψ_E, h/R and "genauer Ausdruck", and says so if the iteration does not settle. h stays 1.8 m and editable, required order stays 2; order 3 stays selectable. Own assumptions, shown in the note: ψ_E as arcsin, d′² left out.
- Modularization: the generator is a pure module in the service package; the page only calls it; the single file is regenerated and checked against its sources. No deferral.
