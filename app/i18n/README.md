# ufAIM large language pack (symbolic)

This package contains a broad i18n skeleton for ufAIM with:
- LTR and RTL language metadata
- ready `de` and `en`
- placeholder files for additional languages discussed for conflict, humanitarian, and railway relevance

## Included languages
de, en, ar, he, fa, ur, uk, ru, fr, zh, ja, hi, tr, ps, my, sw, ht

## Important
- Only `de` and `en` are translated here.
- All other dictionaries intentionally fall back to English values.
- This keeps the package honest while making wiring and later translation easy.

## Suggested next step
Replace placeholder values in `strings.<code>.js` language by language.
